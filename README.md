# ことば · 日语动词实验室

面向中文学习者的离线日语动词实验室：53 个常用动词、26 种词形、11 组自他词对。

## 在线

https://sleevesun.github.io/kotoba-verb-lab/

仓库：https://github.com/sleevesun/kotoba-verb-lab

若站点还没出来：打开仓库 Settings → Pages → Build and deployment → Source 选 **GitHub Actions**，再跑一次 Actions 里的 Deploy GitHub Pages。

## 本地

用浏览器直接打开 `index.html` 即可。学习记录只保存在当前浏览器。
